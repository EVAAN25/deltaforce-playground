    规则说明
    • WASD / 方向键逐格移动，或点击格子自动寻路；走到容器相邻格按 E（或直接点容器）开搜。
    • 搜索逐格开奖：单格耗时按品质递增，「正在搜索」的格子有进度条和翻找声，金 / 红出货有专属音效与光效；搜出的货先进待拾取区，点「入包 / 入箱」取舍——背包格子有限，单格价值（性价比）是关键。
    • 主背包 6×4，被抓全部掉光；安全箱 2×2，死了迷失也保住。每个容器每局只能搜一次。
    • 猛攻队沿固定路线巡逻，有视野半径且会被墙和容器挡住；被看见＝被一脚踢死，本局结束。倒计时 240 秒，超时＝迷失，同样结束。
    • 站到撤离点按 E 引导 5 秒撤离：被猛攻队看见会暂停引导（进度保留，它走远自动继续），自己走动则引导取消重来。带出价值 = 背包 + 安全箱合计，按价值评级 C / B / A / S / SS。
    • 每日一图按本地日期生成，同一天所有人同图同掉落；练习模式随机图不限次。进度与图鉴存在本机浏览器里。

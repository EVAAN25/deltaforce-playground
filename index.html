    规则说明
    • 评级（按带出总价值，被抓/迷失只算安全箱）：SS·鼠王登神 ≥200万；S·肥肥撤离 ≥80万；A·吃得满嘴流油 ≥20万；B·勉强回了本 ≥5万；C·白跑一趟 其余。结算弹卡的表情包和 BGM 按评级分档。
    • 手机 / 触屏：左下摇杆移动（点格子也能自动寻路），右下「交互」= 开搜 / 撤离、「背包」= 整理；搜出货后拖拽或双击入包，包内整理与电脑端一致。页面按设备自动切换桌面 / 触屏形态。
    • WASD / 方向键逐格移动，或点击格子自动寻路；走到容器相邻格按 F（或直接点容器）开搜。
    • 搜索还原官方形态：开箱即见全部物品剪影（占格形状可预判大件），随后自动逐件鉴定——放大镜转圈 + 翻找声，转得越久越值钱；揭晓按品质配真实音效（白蓝/紫/金/红四档），金红带光效。
    • 搜出的货点「入包 / 入箱」、双击、悬停按 F 或拖拽进背包（塞不下时背包会自动整理腾位）；Tab 随时呼出背包整理（Esc 关闭）；包内货可在搜索时拖回容器（或双击/悬停按 F 退回）、同包拖动挪位（贴边自动横竖，可压位互换）；丢弃只能把包内货拖出面板外，没有快捷键。主背包/安全箱尺寸随关卡提升（教学关 5×3+2×2 起步，终章 8×6+3×3 顶配）；主背包被抓全部掉光，安全箱死了迷失也保住。同一容器一局内可反复翻：内容不变、摸过的直接可见，带不走的回头再来拿。容器内容与布局每次首开都随机，爆率以小涛查开容器模拟器实测为基准（品质小幅上浮，非官方概率）。
    • 猛攻队沿固定路线巡逻，有视野半径（红圈）且会被墙和容器挡住；被看见＝被一脚踢死，本局结束。无倒计时，但挂机 5 分钟无操作自动出局（HUD 的 ⏱ 是挂机剩余，操作即重置）。撤离成功 / 被抓 / 迷失各有专属弹卡与 BGM，撤离 BGM 按吃出价值分三档。
    • 站到撤离点按 F 引导撤离，期间不能走动（走了要重新引导）。带出价值 = 背包 + 安全箱合计，按价值评级 C / B / A / S / SS。
    • 关卡模式：零号大坝 → 长弓溪谷 → 巴克什 → 航天基地 → 潮汐监狱 → AZ3核电站 → 火烧长弓/水淹大坝/航天2.0 三张版本活动图压轴，图越来越大、巡逻越来越多、背包安全箱越背越大；每关固定地图，记录每关历史最佳。
    • 每日一图按本地日期生成，同一天所有人同图同掉落；练习模式随机图不限次。进度与图鉴存在本机浏览器里。
